# Requirements

1. Пользователь создаёт проекты.
2. В проекте есть задачи. Задача принадлежит ровно одному проекту.
3. У задачи есть статус, приоритет и необязательный срок.
4. Задачам можно присваивать теги, у задачи их может быть несколько.
5. Задачи можно искать и фильтровать по проекту, статусу, тегу, с пагинацией.

В данном проекте отсутствуют пользователи и авторизация.
